# Video Encoder
Here you will find an encoding kit

## Frame Encoder
A multithread Python image processor and compressor made with Pillow that converts each frame stored on "unprocessed_frames" to a byte array containing compressed frame data and stores it on "frames.bin"

## Base64 Encoder
A custom base64 encoder that converts the compressed binary data into a custom base64 format and outputs the encoded string data into the "b64.txt" file, it is literally the "tab_3.lua" on the PICO-8 video player program
